# Búsqueda diaria de empleo

Proyecto en preparación para ejecutar búsquedas e informes diarios en la nube. Google Drive deja de ser una dependencia.

Por petición del usuario, el repositorio incluye los documentos, historial, informes y archivos originales en [traspaso](traspaso/). Estos archivos contienen datos personales y direcciones de correo. Las credenciales quedan excluidas.

El [registro unificado](traspaso/registro-unificado.json) conserva 5 ofertas, una búsqueda y un envío histórico. Los originales se conservan sin modificaciones. Las instrucciones profesionales completas están en [TRASPASO_NUBE.md](traspaso/traspaso-original/TRASPASO_NUBE.md).

Consulta [el plan adaptado a GitHub](docs/TRASPASO_NUBE.md). Todavía no hay aplicación ejecutable ni programación creada. El repositorio conserva la instantánea inicial; el estado diario necesita almacenamiento persistente y control de concurrencia antes de activar envíos.

Perfil actualizado con las [respuestas sobre prácticas y formación](traspaso/ACTUALIZACION_PERFIL_ANTONIO.md), que complementan las instrucciones originales.
